One line of office comedy for the [make.fun](https://make.fun) competition
**Make the AI Judge Laugh: the Office Joke Open** — $2 winner-takes-all, free to enter.

## The joke

> The meeting could have been an email. The email could have been a Slack message. The Slack message could have been silence.

123 characters. A three-beat escalation whose payoff lands on the very last word.

## How it works

`main.py` writes the joke to `/output/entry.txt`. Nothing else runs; no network,
no secrets. See [`candidates.md`](candidates.md) for the 16 candidates and the
manual ranking against the judge's brief (manual only — no automated judge was
used to pick the winner).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
